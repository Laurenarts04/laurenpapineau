## Project overview

This project was to design and illustrate a poster for this years annual Atelier fashion show. Using our production and layout skills we had to create a strong sense of readability and organization of the information given.

## Tools & Techniques

- Adobe InDesign for layout & production
- Adobe Photoshop for image sizing
- Procreate for illustrations

## Outcomes

This project helped with being able to create a strong poster layout and illustration. The final project file was printed out as 11"x17" poster.
